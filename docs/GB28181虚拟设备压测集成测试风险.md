# GB28181 虚拟设备压测集成测试风险

压测工具的单元测试只验证报文、状态机、RTP 分片和报告逻辑，不会连接真实 WVP、Redis 或 ZLMediaKit。工具现在支持 Digest 注册、Catalog/DeviceInfo 响应、UDP/TCP RTP 和可选 WVP HTTP 点播调度，但真实集成测试仍必须使用隔离的测试网络、测试数据库和测试媒体节点。

执行入口为 `tools/gb28181-load-test/scripts/run-integration.sh`，需要显式设置 `GB28181_LOADTEST_INTEGRATION=1`，避免误连生产环境。默认 numeric 模式生成 20 位纯数字设备/通道 ID；`deviceBase` 和 `channelBase` 必须指向测试专用编号段，不能与生产设备重叠。legacy 模式仍支持 `loadtest-` 前缀，但在 WVP 严格设备 ID 校验开启时会被拒绝。

集成测试前需要确认：

1. SIP 监听地址和端口只对测试网开放；
2. ZLMediaKit 的 RTP 接收端口范围、鉴权和录像目录有容量上限；
3. Redis、MySQL 和 WVP 日志已配置监控与保留策略；
4. 逐级增加设备数和点播数，观察 REGISTER、Invite、RTP 首包、BYE、Redis 内存、连接池和线程池；
5. 测试结束后确认所有虚拟设备已发送 BYE，WVP/ZLM 无残留流、InviteInfo、SIP 会话和临时文件。

推荐场景顺序：10 台基线、100 台阶梯、1,000 台稳定运行、播放 churn、无媒体超时、设备主动 BYE 和网络故障恢复。任何真实环境结果都应保存配置摘要、运行报告和节点监控快照。
