# 真实环境集成测试风险记录

## 媒体节点负载对账

本次媒体节点负载计数修复增加了节点上线和周期性 REST 对账。以下场景必须在真实环境验证，单元测试无法替代：

- ZLM `getMediaList(schema=rtsp)` 返回多个协议记录、重复记录和空数据时，计数是否等于实际业务流数量。
- ABL `getMediaList` 返回重复业务流、非 0 响应和节点不可达时，计数与失败状态是否正确区分。
- WVP 重启后媒体节点已有流，节点上线对账能否恢复 Redis ZSET 负载。
- ZLM/ABL Hook 丢失、重复或乱序时，周期绝对对账能否在一个对账周期内纠正计数。
- 节点接口超时时，对账任务是否在配置的超时内结束，且不阻塞 SIP、HTTP 或定时调度线程。
- 多个节点同时上线或同时触发对账时，同一节点是否不会并发发起重复对账，Redis 分数是否保持绝对值。

建议测试记录至少包含：节点 ID、节点类型、接口耗时、接口返回码、接口返回流数量、对账前后 ZSET 分数和 Hook 时间线。真实环境测试不得修改 `t.cap`。
