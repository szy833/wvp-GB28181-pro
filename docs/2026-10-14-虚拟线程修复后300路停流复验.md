## 验收结论与未覆盖项

- 已验证本次新部署在同机、约 0.209 Mbps 素材、300 路短时三轮点播/观看/并发停止下，业务和终态检查通过，没有再出现旧版持续 HTTP 假死。
- 未直接采集新进程的虚拟线程/JFR pinning 数据；“未复现假死”不是“所有路径永久无 pinning”。
- 未直连 SQL 检查 seq/epoch/state 列；通道流投影 API 和 Invite 终态不能冒充完整数据库代次验收。
- 未执行主动 BYE 专项、慢日志/慢 Redis/慢 ZLM 故障注入、高码率或 30 分钟以上稳态，也未继续升到 500 路。容量上限仍未确定。
- 全路 HTTP-FLV 读取由压测线程完成，仅首末两路用 FFmpeg 解码；未运行浏览器，更没有施加浏览器内存配额。本次不能推出“浏览器可同时分屏 300 路”。
- 本轮自有模拟器、观看、解码和采集进程均已退出，未部署/重启 WVP 或 ZLM，未删除设备、清理 Redis/SQL 或修改产品源码。原代码修复工作区及用户已有本地文件保持不动。
