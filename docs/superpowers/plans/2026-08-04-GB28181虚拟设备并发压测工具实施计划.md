# GB28181 虚拟设备并发压测工具 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `tools/gb28181-load-test/` 创建一个可独立构建的 Go 工具，模拟 GB28181 设备并对 WVP/ZLMediaKit 执行 SIP、RTP 和资源清理并发测试。

**Architecture:** 使用 goroutine 管理虚拟设备；SIP 传输、设备状态机、RTP/PS 发送、场景调度、指标报告分层，通过接口隔离。第一版实现 UDP SIP、UDP RTP/PS、REGISTER/Keepalive/INVITE/200 OK/ACK/BYE 和无媒体超时场景，TCP-PASSIVE 只保留扩展接口，不混入第一版验收。

**Tech Stack:** Go 1.22、标准库 `net`/`context`/`encoding/xml`/`encoding/json`、`gopkg.in/yaml.v3` 配置解析、Prometheus text exposition、Go test/race。

## Global Constraints

- 所有新文件只放在 `/data/shizy/wvp-GB28181-pro/tools/gb28181-load-test/` 及对应设计/计划文档中。
- 不修改 WVP 生产代码，不修改、删除或提交 `t.cap`。
- Git 提交信息使用中文；每个独立任务完成后使用一个中文提交。
- 默认只连接测试 WVP、Redis、MySQL 和 ZLMediaKit，不在工具中内置生产地址。
- 默认设备前缀必须为 `loadtest-`，空前缀、生产前缀和重复运行 ID 直接拒绝启动。
- `go test ./...`、`go test -race ./...` 是工具项目的验证命令；真实 WVP/ZLM 集成测试单独记录，不伪装成单元测试。
