# 默认密码强制修改适配方案与验收

## 范围与实施顺序

基线：`4ea77e4fd07c5419557268a2354b1f259a54434e`。吸收上游 `e80b866d5` 的默认密码功能及 `8fe1d723a` 的校验器意图，不引入其他点播补丁或历史数据库修改。

1. 先增加密码策略、用户更新、鉴权和数据库迁移回归测试，确认旧代码不能满足要求。
2. 适配用户模型、登录结果、过滤器和三个密码写入入口；通用资料更新不允许变更密码或强制改密标记，专用 SQL 原子更新密码和标记。
3. 前端使用统一密码校验函数，适配首次登录、刷新、强制改密、退出和失败响应；保留现有页面风格。
4. 更新新库初始化文件，另提供 MySQL、PostgreSQL/KingBase、H2 的独立幂等增量脚本，不执行实际迁移。
5. 执行后端回归、前端定向测试和可行的构建检查，记录未覆盖的集成风险。

## 行为约定

- 新密码至少 10 位，包含 ASCII 大写、小写、数字和特殊符号；特殊符号为全部 ASCII 标点（包括双引号、反斜杠、方括号和竖线），不允许空白或控制字符；不包含用户名（忽略大小写）。前后端用同一组测试样例验收。
- 默认密码用户可登录、读取当前身份、修改本人密码和退出；普通业务接口及其 API Key 均受限制。身份查询仅用于刷新改密状态，不放开管理能力。
- 接口鉴权关闭时保持原有开关语义；部署强制改密必须开启接口鉴权。
- 只有成功的专用密码更新才将 `default_password` 置为 false，资料/角色/pushKey 更新不得解除限制。
- 保留现有 MD5 入库与 JWT/API Key 生命周期；改密后前端清理登录凭据并要求重新登录，但不宣称服务端已撤销其他已签发 token/API Key。
- 迁移只标记仍使用默认 admin 密码的 admin，不要求全部老用户重置，不覆盖密码、角色、推流密钥或业务表。

## 实施结果

- 补齐 `PasswordComplexityValidator`，四个密码表单共享 `web/src/utils/password-policy.js`。Java 和 JavaScript 使用同一份 JSON 样例，覆盖双引号、反斜杠、方括号、竖线、空白、用户名和弱密码。
- `UserMapper.update()` 不再修改密码或 `default_password`；`changePassword()` 通过单条 SQL 同时修改密码和标记，并拒绝用相同密码解除限制。用户不存在、普通用户调用管理员改密接口均明确失败。
- 本人改密、管理员改密、新增用户均执行后端策略校验。密码入库显式使用 UTF-8 编码的 MD5，保持旧登录协议。
- 登录结果提供 `defaultPassword`；过滤器逐次查询数据库标记，对 access-token、API Key、WebSocket 凭据及已有 User 登录会话一致限制。已删除用户失败关闭；无效/过期 JWT 不再继续执行后续处理链。
- 允许 POST 本人改密、POST 当前身份查询及退出，兼容 context path。普通接口返回带 `defaultPassword=true` 的 JSON 403，前端同步状态并进入强制改密页。
- 页面刷新会查询服务端身份，不依赖可被删除的标记 cookie。请求失败不再被吞为成功，网络断开也不会误清除限制。远端退出失败仍清理本地凭据。
- 改密表单修复 model/确认密码绑定和提交前校验；密码输入默认遮蔽。请求错误不再将含密码参数的整个错误对象打印到控制台。403 导航采用回调写法，兼容项目现有 Vue Router 3.0.6（其 replace 不返回 Promise）。
- 更新 Docker MySQL、MySQL、PostgreSQL/KingBase、H2 的新库初始化文件。未修改或重跑包含其他业务变更的历史升级 SQL。

## 部署顺序（必须执行）

1. 备份现有数据库，记录应用/前端版本；先在备份库验收。停止旧版本应用，不混用仍可绕过改密限制的旧节点。
2. 根据数据库选且仅选下面一份增量脚本，在正确的业务数据库执行。MySQL 整份脚本必须在同一连接执行，不需要创建存储过程权限；DDL 有隐式提交，失败后先检查实际表结构，不假定已整体回滚。
3. 检查 admin 的密码仍为默认值时标记为 true，已改密 admin、普通用户仍为 false；确认密码、角色、pushKey 没有变化。重复执行不会重置已改密用户。
4. 部署匹配的后端与新前端，确认 `user-settings.interface-authentication=true`，使用 HTTPS 或可信加密入口。旧前端没有强制改密页，不能只更新后端。
5. 执行本文件的集成验收表，确认默认 admin 能完成改密及重新登录、普通用户不被误拦截，再恢复服务。回退依赖备份与匹配版本，不建议删除列或重跑初始化 SQL。
